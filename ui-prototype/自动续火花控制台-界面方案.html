账号管理
管理用于续火花的抖音账号：添加 / 切换登录、启用停用。登录凭证保存在本机，不会在界面中明文显示。
每个账号对应一份独立的登录凭证（storage-state.<id>.json）与运行配置（.env.account<id>），互不干扰。设定「默认账号」后，定时任务默认使用该账号运行。

运行说明
正式版本由本地服务调用 Windows 任务计划程序完成注册 / 更新 / 启停
# 正式版本后台执行示例（由界面按钮触发，用户无需手敲）
Register-ScheduledTask -TaskName "DouyinAutoFire" -Trigger (New-ScheduledTaskTrigger -Daily -At 17:20) -Action (New-ScheduledTaskAction -Execute "E:\豆包项目库\自动续火花\.venv\Scripts\python.exe" -Argument "run.py" -WorkingDirectory "E:\豆包项目库\自动续火花")
Set-ScheduledTask -TaskName "DouyinAutoFire" -Settings (New-ScheduledTaskSettingsSet -StartWhenAvailable)
